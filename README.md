# AI Ethics SU

เว็บไซต์พร้อม Deploy บน Vercel

## วิธี Deploy
1. แตกไฟล์ ZIP นี้
2. เข้าเว็บไซต์ Vercel
3. สร้าง Project ใหม่
4. อัปโหลดโค้ดผ่าน GitHub หรือใช้ Vercel CLI
5. ไฟล์ index.html เป็นหน้าเว็บไซต์หลัก

หมายเหตุ:
- เว็บไซต์เวอร์ชันนี้เป็น Static Website และใช้งานบน Vercel ได้
- ระบบข้อมูลผู้เรียนปัจจุบันใช้ localStorage ในเบราว์เซอร์
- หากต้องการข้อมูล Real-time ร่วมกันของผู้ใช้ทุกคน ต้องเชื่อมฐานข้อมูลเพิ่มเติม เช่น Supabase หรือ Firebase
